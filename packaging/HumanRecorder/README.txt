HumanRecorder 玩家数据记录工具
版本：0.5.3-internal

====================
这个工具是做什么的？
====================

HumanRecorder 会在你正常游玩《杀戮尖塔 2》时，自动记录你看到的游戏状态和你做出的选择，例如：

· 打出了哪张牌、选择了哪个目标
· 什么时候结束回合或使用、丢弃药水
· 选择了哪条路线
· 抓了哪张牌，或选择跳过
· 在事件、营火、宝箱和商店里做了什么
· 当前的血量、金币、卡组、遗物、药水和敌人状态
· 游戏种子、游戏版本、加载的 Mod，以及存档重载（俗称 SL）

它不会替你操作游戏，也不会改变你的游戏策略。安装以后，像平常一样玩即可。


====================
安装前请确认
====================

1. 目前只支持《杀戮尖塔 2》v0.107.1（Steam build 23811903）。
2. 只支持 Windows 版。
3. 安装时必须先关闭游戏。
4. 请先把下载的 ZIP 压缩包完整解压，不要直接在压缩包里面运行文件。

如果游戏版本不正确，安装程序会停止并显示错误，不会修改游戏文件。


====================
如何找到游戏文件夹
====================

1. 打开 Steam。
2. 在“库”中找到《Slay the Spire 2》并点击右键。
3. 选择“管理”→“浏览本地文件”。
4. 系统会打开游戏文件夹。
5. 点击文件资源管理器上方的地址栏，复制完整地址。

地址通常类似下面这样：

C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2

如果你把 Steam 游戏安装在其他硬盘，也可能类似：

D:\SteamLibrary\steamapps\common\Slay the Spire 2


====================
安装方法
====================

1. 打开刚刚解压出来的 HumanRecorder 文件夹。
2. 在文件夹空白处按住 Shift，再点击鼠标右键。
3. 选择“在终端中打开”或“在此处打开 PowerShell 窗口”。
4. 复制下面的命令，把双引号中的地址换成你刚才复制的游戏文件夹地址，然后按回车：

powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -GameRoot "D:\SteamLibrary\steamapps\common\Slay the Spire 2"

请保留地址两边的英文双引号。

安装成功后，会显示 HumanRecorder.dll 和 HumanRecorder.json 两个文件。安装只需要进行一次。


====================
如何开始记录
====================

1. 正常启动游戏。
2. 开始一局新的单人游戏。
3. 正常游玩，无需按“开始记录”，也无需保持安装窗口打开。
4. 游戏结束、失败或放弃时，记录会自动保存。

战斗中退出再进入、重新读档或使用 QuickSL 都可以。Recorder 会把被撤销的操作和最后保留的操作分开标记，不会简单地把它们混成一条路线。

游戏画面右侧、中间偏上的位置会显示“Act N、层 N”和记录状态，不再读取或显示战斗回合。绿色表示正常记录，灰色表示待机，黄色表示正在恢复 SL，橙色表示本局存在记录警告，红色表示记录已经停止。

请不要在游戏仍在运行时移动、删除或修改记录文件。


====================
如何确认它正在工作
====================

完成至少一个游戏内选择后，回到 HumanRecorder 文件夹，在终端中运行：

powershell -NoProfile -ExecutionPolicy Bypass -File .\check_status.ps1

看到下面任意一种状态，说明工作正常：

· recording：正在记录一局游戏
· ready：Recorder 已加载，目前没有正在记录的游戏

“LastError”为空是正常情况。

如果还没有开始过新的一局，状态文件可能暂时不存在，这也是正常的。


====================
记录保存在哪里
====================

按下键盘上的 Win + R，复制下面这一行并按回车：

%LOCALAPPDATA%\SlayTheSpire2\HumanRecorder\inbox

这里每个以 human- 开头、以 .jsonl 结尾的文件，通常代表一局已经保存完成的游戏。

文件可能有几十 MB，这是正常的。请不要使用记事本打开或修改这些文件。


====================
如何把记录打包发给收集者
====================

1. 先关闭游戏，确保本局已经保存完成。
2. 回到解压出的 HumanRecorder 文件夹。
3. 在该文件夹打开终端。
4. 运行：

powershell -NoProfile -ExecutionPolicy Bypass -File .\collect_records.ps1

完成后，这个文件夹里会出现一个名称类似下面这样的压缩包：

HumanRecorder-20260807-180000.zip

只需要把这个 ZIP 文件发给数据收集者。原始记录仍会保留在你的电脑上，不会被自动删除。

注意：这个命令会打包目前所有已经完成的记录。如果你以前发送过数据，请告诉收集者，系统会通过文件校验值自动识别重复文件。


====================
隐私说明
====================

Recorder 会保存：

· 游戏中的选择和状态
· 游戏种子和记录时间
· 一个随机生成的匿名玩家编号
· 已加载 Mod 的名称、版本和文件校验值

Recorder 不会保存：

· Steam 账号或密码
· 键盘输入内容
· 鼠标移动轨迹
· 屏幕截图或录像
· 聊天内容
· Recorder 文件夹以外的个人文件

记录时间可能大致反映你的游玩时间。只有在你愿意分享这些信息时，才把压缩包发给收集者。更完整的说明见 PRIVACY.md。


====================
如何卸载
====================

先关闭游戏，然后在 HumanRecorder 文件夹的终端中运行：

powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1 -GameRoot "D:\SteamLibrary\steamapps\common\Slay the Spire 2"

同样需要把双引号中的地址换成你的游戏文件夹地址。

卸载只会删除 Recorder 本身，不会删除已经保存的游戏记录。


====================
遇到问题怎么办
====================

安装程序提示“不是游戏目录”：
请重新按照“如何找到游戏文件夹”复制地址。正确的文件夹中应该能看到游戏程序和 data_sts2_windows_x86_64 文件夹。

安装程序提示版本不兼容：
说明当前游戏不是 Recorder 支持的 v0.107.1。请停止安装并联系数据收集者，不要强行复制 DLL。

Windows 阻止运行脚本：
确认你使用的是本说明中的完整 powershell 命令。如果压缩包是从网络下载的，也可以右键点击 ZIP →“属性”→勾选“解除锁定”，然后重新解压。

check_status 没有显示 recording 或 ready：
先确认安装成功，再启动游戏并新开一局单人游戏，完成一个选择后重新检查。

游戏发生崩溃：
不要删除记录目录。未完成的记录通常会以 .partial 结尾，也有助于排查问题。把问题发生的大致时间和操作告诉数据收集者。

游戏出现明显卡顿或其他异常：
先退出游戏，再卸载 Recorder。已经保存的记录不会丢失。请把发生卡顿时的大致场景告诉数据收集者，例如“多敌人战斗”“商店删牌”或“连续 SL”。


感谢你帮助收集真实玩家数据。
