# 战斗反事实排序调优 V0

## 结论

真实引擎终局标签能够发现 P2 的候选排序错误，但当前两种低成本注入方式均未通过接管门禁：

- 全局微调候选评分器最后一层，会明显破坏普通人工状态的动作预测；
- 仅微调 Encounter Embedding 能限制影响范围，但不足以稳定翻转真正错误的首选动作。

因此没有候选模型替换 P2，P2 继续作为默认战斗 Policy。

## 数据扩展

### 30 场双根实验

每场选择“最高风险根 + 最早触发根”：

```text
战斗                         30
反事实根                     60
教师可用根                   60
有信息量根                   29
P2 首选被推翻的根             13
终局 world                  358
```

最高风险根只有 6/30 有信息量；最早触发根为 23/30，并贡献 12/13 个首选纠错标签。

### 60 场最早根实验

停止采集低收益的末期根，每场只展开最早触发状态：

```text
战斗                         60
教师可用根                   60
有信息量根                   45
P2 首选被推翻的根             22
成对标签                    109
终局 world                  360
墙钟时间                 356.77 s
```

有效根在 Act 1/2/3 分布为 17/16/12，纠错根为 7/8/7。数据仍是失败导向而非均匀抽样：Bowlbugs Weak、Soul Nexus 和 Bygone Effigy 合计占 34/60 场，后续不能把它当作通用战斗分布。

## 调优实验

### 全局候选末层

只开放 P2 `candidate_scorer` 最后一层，共 129 个参数，其余网络冻结。损失包括：

- 终局成对排序；
- Top-k 内教师最佳动作的 listwise 监督；
- 1024 条人工动作 BC anchor；
- 对原始 P2 分布的蒸馏约束。

在 45 根数据上的结果：

| 指标 | P2 | 调优后 |
|---|---:|---:|
| 反事实 holdout 成对准确率 | 34.78% | 60.87% |
| 错误首选纠正率 | 0/5 | 1/5 |
| 人工 validation Top-1 | 58.86% | 54.85% |

它能学习反事实排序，但以 4.01 个百分点的常规能力下降为代价，超过 0.5 个百分点门槛，因此拒绝。

### 规则触发式双模型

如果仅在风险/OOD信号触发时使用全局调优模型：

| 门控 | 接管率 | 人工 validation Top-1 变化 |
|---|---:|---:|
| 任一信号 | 68.02% | -3.35 pp |
| 至少两个信号 | 34.67% | -2.16 pp |
| 风险与不确定性同时出现 | 25.03% | -1.44 pp |
| 严格组合 | 21.26% | -0.90 pp |

严格组合仍未通过 0.5 pp 门槛。更根本的问题是：13 个早期纠错根中有 8 个只有“可见承伤高”信号，而该信号在人工验证集中出现 733 次。固定规则无法同时获得高召回和低误接管。

### Encounter Embedding 局部适配

以已有 P2 Encounter Residual 模型为基础，只开放 Encounter Embedding。较强设置结果：

| 指标 | Encounter baseline | 调优后 |
|---|---:|---:|
| 反事实 holdout 成对准确率 | 34.78% | 39.13% |
| 错误首选纠正率 | 0/5 | 0/5 |
| 人工 validation Top-1 | 58.68% | 57.19% |

虽然变化局部化，但仍没有纠正错误首选且损失 1.50 pp，故拒绝。门禁已补充“离散排序或错误首选必须改善”，不能只因连续 loss 下降而接受。

## 数据和标签边界

这些标签仍是共同 determinization、冻结 P2 continuation 下的 `Q^{P2}(s,a)`，不是最优 `Q*`。每个动作当前只有两组 determinization；对于生成卡牌、随机目标等高随机动作，只能视为先导监督。

反事实数据来自训练 split；内部 holdout 按 scenario 分组。人工 validation 只用于模型选择，不能再作为最终测试结论。没有任何被拒绝的候选进入真实战斗默认路径。

## 下一步

下一版不再直接改写原 Policy 参数，而应构建独立的条件残差与接管器：

1. 保留 P2 logits 作为不可变基线；
2. 用反事实根训练候选 residual，同时加入 Policy 正确和动作平局根作为“不要接管”负样本；
3. 接管器同时读取敌人身份、P2 margin/entropy、精确候选特征和 residual 置信度；
4. 对重复过多的三类敌人限额，补充 encounter-balanced 训练根；
5. 先要求反事实 holdout 的错误首选纠正率提高，再要求人工 validation 下降不超过 0.5 pp；
6. 两道门槛通过后，才运行真实引擎 validation 战损测试。

当前结果不是“搜索教师无效”，而是证明少量终局标签不能安全地通过一个全局参数更新传播到所有状态。后续重点应从继续增加全局训练强度，转向局部残差、负样本和学习式接管。
